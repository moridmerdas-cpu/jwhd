# عضویت اجباریه سپر — ربات عمومی و رایگان جوین اجباری (چند-مستاجری)

## تغییرات این نسخه نسبت به قبل

- ربات دیگر فقط یک گروه ندارد؛ **هرکسی می‌تواند گروه خودش را ثبت کند** و فقط برای همان گروه
  آیتم جوین اجباری تعریف کند (کانال/گروه/ربات).
- **مالک اصلی ربات** آیدی عددی `8977934490` (یا هر چیزی که در `SUPER_OWNER_ID` ست کنید) است.
  هر آیتمی که او اضافه کند **سراسری** است و خودکار روی همه‌ی گروه‌های ثبت‌شده در ربات اعمال می‌شود.
- بقیه‌ی کاربران فقط می‌توانند برای گروه خودشان آیتم اضافه/حذف/ویرایش کنند.
- ثبت گروه فقط وقتی قبول می‌شود که ربات بررسی کند شما واقعاً در آن گروه ادمین/مالک هستید
  (جلوی تصاحب گروه دیگران را می‌گیرد).

## نصب و اجرای پایگاه‌داده

۱) جدول‌های جدید را در SQL editor پروژه‌ی Supabase اجرا کنید — دستورات کامل داخل
   داکیومنت بالای فایل `bot.py` هست (بخش «جدول‌های مورد نیاز»).
   اگر از نسخه‌ی قبلی (تک‌گروهی) مهاجرت می‌کنید، بخش «مهاجرت» همان داکیومنت را اجرا کنید.

۲) متغیرهای محیطی:
   - `BOT_TOKEN` → توکن ربات از @BotFather
   - `SUPABASE_URL` / `SUPABASE_KEY`
   - `SUPER_OWNER_ID` (اختیاری — پیش‌فرض همان `8977934490` است)
   - `WEBHOOK_URL` یا دیپلوی روی Render (که خودش `RENDER_EXTERNAL_URL` را ست می‌کند)

```bash
pip install -r requirements.txt
python bot.py
```

## استفاده (برای هر کاربر عادی)

۱. ربات را در گروه‌تان **ادمین** کنید (دسترسی حذف پیام).
۲. در پیوی ربات `/start` بزنید → «➕ ثبت گروه جدید» → یک پیام از گروه فوروارد کنید یا آیدی عددی‌اش را بفرستید.
۳. بعد از ثبت، از همان پنل: «📋 مدیریت آیتم‌ها» → افزودن کانال/گروه/ربات که اعضا باید عضوشان باشند — این آیتم‌ها فقط در همین گروه اعمال می‌شوند.
۴. اگر چند گروه دارید، هر کدام جدا ثبت می‌شود و پنل جداگانه‌ای دارد («🔁 تغییر گروه»).

## استفاده (مالک اصلی ربات)

در پیوی ربات `/start` بزنید → «🌐 آیتم‌های سراسری» → هر چیزی که اینجا اضافه شود، روی
**همه‌ی گروه‌های ثبت‌شده در ربات** اعمال می‌شود (علامت 🌐 کنار آن در لیست آیتم‌ها دیده می‌شود).
آیتم‌های سراسری فقط توسط همان مالک اصلی قابل ویرایش/حذف هستند.

## مصرف اینترنت

ربات از ابتدا روی **webhook** کار می‌کند (نه polling) که خودش بیشترین صرفه‌جویی ترافیک را
می‌دهد؛ تلگرام فقط وقتی آپدیتی هست به سرور شما وصل می‌شود. علاوه بر آن:
- نتایج تنظیمات/آیتم‌ها/متن‌ها تا ۲۰ ثانیه کش می‌شوند.
- تشخیص اینکه یک پیام گروه مربوط به کدام گروهِ ثبت‌شده است، ۳۰ ثانیه کش می‌شود (این هر پیام گروه را صدا می‌زند، پس داغ‌ترین مسیر است).
- بررسی عضویت هر کاربر هم تا ۲۰ ثانیه کش می‌شود، و چند پیام هم‌زمان از یک کاربر فقط یک تماس API می‌زنند.
با این حالت، مصرف واقعی برای یک ربات معمولی (چند ده گروه، چند صد پیام در روز) معمولاً چند
مگابایت در ماه است، نه گیگابایت؛ محدودیت ۵ گیگابایت عملاً خیلی راحت رعایت می‌شود. اگر گروه‌ها
زیاد شدند (چند هزارتا) و خواستید باز هم سخت‌گیرتر شوید، می‌توانید `CACHE_TTL_SECONDS` و
`GROUP_LOOKUP_TTL_SECONDS` در بالای `bot.py` را بیشتر کنید.

# ربات جوین اجباری تلگرام

## نصب

```bash
pip install -r requirements.txt
```

## تنظیم اولیه

1. فایل `bot.py` را باز کنید و مقادیر زیر را وارد کنید:
   - `BOT_TOKEN` → توکن ربات از @BotFather
   - `OWNER_ID` → آیدی عددی خودتان (از @userinfobot بگیرید)
2. ربات را اجرا کنید:
   ```bash
   python bot.py
   ```
3. ربات را در گروه مورد نظر **ادمین** کنید (با دسترسی حذف پیام).
4. ربات را در کانال‌های جوین اجباری هم **ادمین** کنید (با دسترسی ساخت لینک دعوت در صورت نیاز).
5. در پیوی ربات دستور `/start` را بزنید تا پنل مدیریت باز شود.
6. از پنل: «تنظیم گروه» → یک پیام از گروه فوروارد کنید یا آیدی عددی گروه را بفرستید.
7. از پنل: «مدیریت کانال‌ها» → «افزودن کانال» → یک پیام از کانال فوروارد کنید، یا دستی به فرمت زیر بفرستید:
   ```
   @channel_username | https://t.me/channel_username
   ```

## ویرایش متن‌ها

از پنل مدیریت → «ویرایش متن‌ها» → متن هشدار یا متن تایید عضویت را ویرایش کنید.

متغیرهای قابل استفاده در متن‌ها:
- `{mention}`
- `منشن_کاربر`

هرکدام را در متن بگذارید، جای منشن کاربر قرار می‌گیرد. اگر هیچ‌کدام را نگذارید، منشن به‌صورت خودکار در ابتدای پیام اضافه می‌شود (چون تگ کردن کاربر الزامی است).

## نکته درباره رنگ دکمه‌ها

قابلیت رنگی‌کردن دکمه‌های شیشه‌ای (inline keyboard) از سمت کد ربات در API رسمی تلگرام برای بات‌ها وجود ندارد؛ این ویژگی صرفاً از سمت کلاینت/کاربر برای شخصی‌سازی ظاهریست و پارامتری در سطح Bot API برایش تعریف نشده، پس در کد قابل تحمیل نیست.

## محدودیت‌های اعمال‌شده طبق درخواست

- ربات فقط در یک گروه (تعیین‌شده توسط مالک) فعال است.
- فقط مالک (`OWNER_ID`) به پنل مدیریت در پیوی دسترسی دارد.
- کانال‌ها قابل افزودن/حذف هستند.
- منشن کاربر در تمام پیام‌های هشدار/تایید اجباری و تضمین‌شده است.
- پیام کاربر غیرعضو حذف و پیام هشدار جایگزین می‌شود؛ با تایید عضویت، همان پیام ادیت می‌شود.

## آیتم نوع «ربات» (بدون نیاز به دیتابیس مشترک)

از پنل: «مدیریت آیتم‌ها» → «افزودن ربات» → یوزرنیم (`@id_bot`)، لینک (`https://t.me/id_bot`) یا لینک با پارامتر (`https://t.me/id_bot?start=ref123`) را بفرستید.

- دکمه‌ی ربات یک لینک مستقیم است و پیوی ربات مقصد با دکمه‌ی Start باز می‌شود.
- ربات بررسی واقعی ندارد؛ زدن دکمه‌ی «بررسی عضویت» ورود کاربر به همه‌ی ربات‌ها را تایید می‌کند.
- نیازی به تغییر در ربات مقصد یا دیتابیس مشترک نیست.
- کانال‌ها و گروه‌ها همچنان با `getChatMember` واقعی بررسی می‌شوند.
- در مدیریت هر ربات، دکمه‌ی «کاربران عضو شده» تعداد کاربران تاییدشده را نشان می‌دهد.

## رفتار پیام هشدار

- فقط مواردی که کاربر هنوز در آن‌ها عضو نیست نمایش داده می‌شود؛ با «بررسی عضویت» دکمه‌ی مواردی که عضو شده حذف می‌شود.
- لیست موارد باقی‌مانده داخل نقل قول (blockquote) چاپ می‌شود و متن‌های پیش‌فرض بولد هستند.
- متن‌هایی که مالک در پیوی تنظیم می‌کند با تمام قالب‌بندی‌اش ذخیره و همان‌طور ارسال می‌شود.
- دکمه‌های «بررسی عضویت» فقط برای کاربرِ هدفِ پیام فعال هستند.

## سرعت حذف پیام‌ها

- هر پیام غیرعضو بلافاصله و مستقل حذف می‌شود (ده پیام هم‌زمان = ده حذف هم‌زمان) و بعد از حذف، فقط **یک** هشدار برای هر کاربر ارسال می‌شود.
- حذف با تلاش مجدد روی محدودیت نرخ تلگرام (RetryAfter) و خطای شبکه انجام می‌شود.
- تنظیمات، آیتم‌ها و متن‌ها ۱۵ ثانیه کش می‌شوند (با هر تغییر ادمین بلافاصله پاک می‌شود) و بررسی عضویت چند پیام هم‌زمان یک کاربر فقط یک بار انجام می‌شود.

## تایید خودکار عضویت

- وقتی کاربر در کانال/گروه جوین اجباری عضو می‌شود، پیام هشدارش خودکار ادیت می‌شود: دکمه‌ی همان مورد حذف می‌شود و وقتی همه کامل شد متن «تایید عضویت» جایگزین می‌شود. نیازی به زدن «بررسی عضویت» نیست.
- ورود به ربات‌ها هم وقتی همه‌ی کانال/گروه‌ها کامل شد خودکار تایید می‌شود.
- **شرط:** ربات باید در همه‌ی کانال‌ها/گروه‌های جوین اجباری **ادمین** باشد تا تلگرام رویداد `chat_member` را بفرستد.
- دکمه‌ی «بررسی عضویت» به‌عنوان جایگزین باقی مانده (مثلاً برای کاربری که از قبل عضو کانال‌ها بوده و فقط ربات‌ها مانده).
- دکمه‌های پیام هشدار در گروه رنگ ندارند؛ فقط دکمه‌های پنل مدیریت رنگی هستند.

## تنظیم زمان آیتم‌ها (دکمه‌های «تنظیم هم اکنون» و «تنظیم زمان»)

بعد از افزودن هر کانال/گروه/ربات در پنل، دو دکمه می‌آید (این دو دکمه در صفحه‌ی مدیریت هر آیتم هم هست):

- **⚡ تنظیم هم اکنون:** آیتم همین لحظه فعال می‌شود و محدودیت زمانی ندارد.
- **⏰ تنظیم زمان:** مدت فعال بودن را می‌فرستید (`30m` دقیقه، `12h` ساعت، `7d` روز، `90 دقیقه`، `2 روز`؛ فقط عدد = ساعت). بعد از پایان مدت، آیتم خودکار از جوین اجباری کنار می‌رود (حذف نمی‌شود؛ در لیست پنل با ⛔️ دیده می‌شود و می‌توانید دوباره زمان بدهید یا حذفش کنید).

**فقط یک‌بار در Supabase اجرا کنید:**

```sql
alter table channels add column if not exists expires_at timestamptz;
```
